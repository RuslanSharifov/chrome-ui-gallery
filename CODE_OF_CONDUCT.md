# Community Code of Conduct

Chrome UI Gallery is a welcoming project for developers of every experience level.

## Our standards

Be respectful and constructive. Give actionable code reviews; assume good intent without ignoring harmful behavior. Respect different backgrounds, abilities, cultures and technical skill levels.

Unacceptable behavior includes harassment, threats, hate speech, sexual harassment, doxxing, trolling, repeated personal attacks, and publishing another person's private data or credentials.

## Scope

These expectations apply to project issues, pull requests, comments and other community spaces connected to the gallery.

## Enforcement and reporting

Maintainers may remove disruptive content, request changes, restrict participation or ban repeat offenders. For non-sensitive conduct concerns, open an issue with **Community / moderation** in the title. If an issue contains private information or puts someone at risk, use GitHub's repository-owner contact channels instead of a public issue.

Reports will be considered as fairly and confidentially as the available GitHub communication channels allow. Retaliation against anyone raising a concern is not tolerated.

## Attribution

This is a short project-specific conduct policy; it is not presented as an official adoption of a third-party template.
