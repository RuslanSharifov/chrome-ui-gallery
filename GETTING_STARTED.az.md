## 1. İstədiyin əlavəni seç

- **Saytın görünüşünü dəyişmək üçün:** [UI dizaynları](./ui/README.md).
- **Faydalı brauzer alətləri üçün:** [Tools bölməsi](./Tools/README.md).

Seçdiyin əlavənin **README.md** faylını oxu.

## 2. Repository-ni yüklə

1. [GitHub səhifəsini](https://github.com/RuslanSharifov/chrome-ui-gallery) aç.
2. **Code → Download ZIP** seç və ZIP faylını arxivdən çıxar.
3. **chrome-ui-gallery-main** folderini aç.
4. İstədiyin əlavənin **manifest.json** olan xüsusi folderini tap.

## 3. Chrome-a əlavə et

1. Chrome ünvan sətrinə **chrome://extensions** yaz.
2. Sağ yuxarıda **Developer mode** rejimini aktiv et.
3. **Load unpacked** düyməsini seç.
4. **manifest.json** faylının olduğu konkret extension folderini göstər.
5. Əlavə quraşdırıldıqdan sonra lazım olan saytı yenilə.

**Diqqət:** Bütöv **chrome-ui-gallery-main** folderini seçmə. Mütləq ayrıca extension folderini seç.

## 4. Səhv yaranarsa

| Problem | Həll |
| :--- | :--- |
| Manifest file is missing | İçərisində **manifest.json** olan düzgün folderi seç. |
| Əlavə işləmirsə | Extension aktiv olsun; saytı yenilə və **Errors** bölməsinə bax. |
| İkon görünmürsə | **icons/** fayllarının mövcudluğunu yoxla. |
| İcazələr çox genişdirsə | Quraşdırmazdan əvvəl README və manifestdəki icazələri nəzərdən keçir. |
