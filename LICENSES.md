## Default policy

The root [MIT License](./LICENSE) covers original material owned by this project and contributions whose authors have granted those rights. It **does not override** separate licenses attached to imported work, nor does the public visibility of third-party code automatically grant reuse rights.

## Important distinctions

- The folder [Tools/chatgpt-lag-fixer/licenses/](./Tools/chatgpt-lag-fixer/licenses/README.md) contains **alternative license reference material**. Its Apache/GPL documents link to official full texts and are not applicable licenses for the project. The operative license for that tool is its [root MIT LICENSE](./Tools/chatgpt-lag-fixer/LICENSE).
- Product names and trademarks such as ChatGPT, Gemini, GitHub and Lovable belong to their respective owners. Gallery themes are independent, unofficial experiments.
- A sample's inclusion in the gallery is not proof that every image, font, icon or third-party component in it has been audited for redistribution rights.

## New submissions

Contributors must document:
1. Original author and GitHub handle.
2. SPDX license identifier and, if different from the gallery MIT default, the actual license/notice file and permission to redistribute.
3. Third-party fonts, libraries, SVGs, screenshots, brand marks and original source URLs.
4. Any restrictions on redistribution.

The maintainer should resolve unclear provenance **before merging**. Copyright or license disputes: see [SECURITY.md](./SECURITY.md) for contact guidance, or open a non-sensitive issue.

*This inventory is a repository-level check, not a legal opinion or verification of every asset's ownership.*
