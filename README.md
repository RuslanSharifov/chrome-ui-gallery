# Chrome UI Gallery

An open-source collection of browser interface designs, Chrome extensions and developer tools. Explore the [live gallery](https://ruslansharifov.github.io/chrome-ui-gallery/), browse the [UI designs](./ui-designs/README.md), explore [tools](./Tools/README.md), or read about the [applications](./apps/README.md).

## English
Chrome UI Gallery showcases customizable browser interfaces, open-source Chrome extensions and useful developer tools. Source code and documentation are publicly available.
