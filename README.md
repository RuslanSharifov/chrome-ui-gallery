# Chrome UI Gallery

An open-source collection of customizable browser interfaces, Chrome extensions, and developer tools.

[Live website](https://ruslansharifov.github.io/chrome-ui-gallery/) · [UI designs](./ui-designs/README.md) · [Developer tools](./Tools/README.md) · [Applications](./apps/README.md)

## English
Chrome UI Gallery brings together customizable browser designs, open-source Chrome extensions, and developer utilities. Explore previews, download extensions, or inspect their source code.
