# Contributing

Thanks for your interest in contributing!

1. Fork the repository and create a branch from `main`.
2. Make your changes. Keep them small and focused.
3. Test by loading the extension unpacked and checking a long ChatGPT conversation.
4. Open a pull request describing what changed and why.

## Guidelines

- Keep the extension dependency-free (plain JavaScript and CSS).
- Do not add data collection or network requests.
- Use clear commit messages.
