# License Options

This folder contains license texts you can choose from when publishing the project. Copy the chosen file to the project root as `LICENSE` and update the copyright line.

| License | File | Summary |
| --- | --- | --- |
| MIT | [MIT.md](MIT.md) | Very permissive. Reuse allowed with the copyright notice kept. |
| BSD 3-Clause | [BSD-3-Clause.md](BSD-3-Clause.md) | Permissive. Like MIT, but forbids using contributor names for endorsement. |
| Apache 2.0 | [Apache-2.0.md](Apache-2.0.md) | Permissive, with an explicit patent grant. |
| GPL 3.0 | [GPL-3.0.md](GPL-3.0.md) | Copyleft. Derivative works must also be released under GPL. |

The project currently uses **MIT** (see the root `LICENSE` file).

> This is general information, not legal advice. Check the full license text on the official site before use.
