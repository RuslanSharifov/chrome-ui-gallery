02
UNPACK THE FILES

Extract the ZIP (do not run it inside the ZIP)

Open File Explorer → Downloads. Right-click chrome-ui-gallery-main.zip, select Extract All…, choose a location such as your Desktop, and click Extract. Open the extracted chrome-ui-gallery-main folder.

03
ONE-TIME REQUIREMENT

Install Node.js

The ZIP contains source code. To run this Electron desktop application, install Node.js 22 or newer first. On the official Node.js website choose the LTS Windows installer, open the downloaded installer, click Next through the steps and finish. Keep npm enabled.

Open official Node.js download ↗

After installation, open a new PowerShell window. Run the command below; it should print a version starting with v22 or higher.

node --version

04
OPEN THE RIGHT FOLDER

Open PowerShell in the project

Open your extracted chrome-ui-gallery-main folder in File Explorer. Click the address bar at the top (where the folder path appears), type powershell and press Enter. A PowerShell window opens inside this exact folder.

05
START THE DESKTOP APP

Install dependencies and launch

In the PowerShell window, paste and run these commands one at a time. Press Enter after each command. The first install can show many lines and might take time.

cd apps\desktop
npm install
npm run dev
Expected result: Chrome UI Gallery Desktop opens as a separate application window. Keep PowerShell open while using the development build. To stop, return to PowerShell and press Ctrl + C.

If you close PowerShell, open it again in chrome-ui-gallery-main, run cd apps\desktop and then npm run dev. You normally do not need to repeat npm install unless dependencies change.

06
OPTIONAL CHROME CONNECTION

Install Gallery Companion

You can browse the Desktop app without this step. If you want to manage installed Chrome extensions through the app, install its Companion extension:

  1. In Chrome, enter chrome://extensions in the address bar and press Enter.
  2. Switch on Developer mode (usually at the top right).
  3. Click Load unpacked.
  4. Browse to your extracted chrome-ui-gallery-main → browser-bridge → manager-extension folder. Select the folder containing manifest.json.
  5. Open Chrome UI Gallery Desktop → Settings, and find the pairing code.
  6. Click the Gallery Companion extension icon in Chrome (use the puzzle-piece Extensions menu if hidden). Paste the code with Ctrl + V and click Connect to Desktop.
  7. Once paired, the companion should show Desktop connected. Keep the Desktop application open for synchronization.

NEED HELP?

Common problems, simple fixes

“node” or “npm” is not recognized

Finish installing Node.js LTS, close PowerShell completely and reopen it. Check with node --version and npm --version.

Cannot find module “adm-zip”

In apps\desktop, run npm install again. Check you downloaded the latest source ZIP.

I cannot find “Load unpacked”

Open chrome://extensions in Chrome and enable Developer mode. Then look near the top of the page.

Chrome will not load the extension

Choose the manager-extension folder itself, not the repository ZIP or the parent browser-bridge folder. You must see manifest.json inside.

I downloaded a ZIP, where is the .exe?

That ZIP is source code; there is no executable inside. Check the official Releases page for future installer assets or use the steps above to run from source.

Windows PowerShell blocks npm.ps1

Rather than modifying system security policies, open Command Prompt (cmd) in the project folder and run the same commands there, or use npm.cmd install and npm.cmd run dev in PowerShell.
