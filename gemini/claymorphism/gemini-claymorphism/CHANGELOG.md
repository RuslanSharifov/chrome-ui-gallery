# Changelog

## 1.0.0

- Added the Gemini Claymorphism visual layer.
- Added pastel clay surface styling for Gemini navigation, conversation, composer, dialogs, menus, cards, code blocks, and controls.
- Added animated 3D clay clouds rendered locally with CSS shapes.
- Added cloud speed, size, count, opacity, and depth controls.
- Added cursor parallax and optional 3D navigation hover.
- Added light and dark mode detection.
- Added persistent popup settings with presets.
