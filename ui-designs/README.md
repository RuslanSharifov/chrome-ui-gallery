## Platform-specific browser tools

General browser tools are kept in [Tools/](../Tools/README.md). A tool designed specifically for a platform lives inside that platform's style/category folder (for example `ui-designs/youtube/utilities/`). Its [gallery metadata](../docs/CATALOG.md) may mark it as category `tool` while preserving the platform hierarchy.

## Add a platform or design

See [contribution rules](../CONTRIBUTING.md) and the [navigation policy](../docs/NAVIGATION.md). A new platform requires a platform README, each style a style README and each extension a design/README beside `manifest.json`. The website catalog is generated from manifests; documentation links are maintained explicitly.
