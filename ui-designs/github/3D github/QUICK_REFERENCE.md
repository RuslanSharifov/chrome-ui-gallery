# GitHub Glassmorphism Pro - Quick Reference Guide

## 🎮 Quick Settings Map

### THEME TAB
```
Visual theme selector
├─ Aurora Glass ...................... Balanced blue/purple
├─ X-Matrix / Green .................. Hacker mode with code
├─ Ice Light ......................... Cool blues and whites
├─ Neon Pulse ........................ Vibrant cyan/magenta
├─ Midnight .......................... Deep blue theme
└─ Minimal Glass ..................... Lightweight subtle

Color intensity (%) .................. 90 → 210
  └─ Boost vibrance (default: 155%)

Text contrast (%) .................... 70 → 120
  └─ Adjust readability (default: 94%)

Ambient glow ......................... ON/OFF
  └─ Soft lighting background (default: ON)
```

### GLASS TAB (NEW!)
```
Glass blur (px) ...................... 6 → 46
  └─ Blur intensity (default: 24px)
  └─ Tips: 6=crisp, 24=moderate, 46=very blurred

Glass opacity (%) .................... 25 → 82
  └─ Transparency level (default: 58%)
  └─ Tips: 25=transparent, 82=opaque

Corner radius (px) ................... 6 → 30
  └─ Rounded corner amount (default: 18px)
  └─ Tips: 6=sharp, 18=moderate, 30=very rounded

Edge shine (%) ....................... 0 → 120
  └─ Highlight brightness (default: 72%)
  └─ Tips: 0=no shine, 72=medium, 120=very bright

Background dim (%) ................... 0 → 45
  └─ Darken background (default: 0%)
  └─ Tips: 0=bright, 25=medium, 45=very dark

Glass borders ........................ ON/OFF
  └─ Luminous outlines (default: ON)
```

### 3D/PROXIMITY TAB
```
3D depth effect ...................... ON/OFF
  └─ Enable 3D transforms (default: ON)

Depth strength (%) ................... 0 → 28
  └─ 3D rotation amount (default: 12%)
  └─ Tips: 0=flat, 12=moderate, 28=very deep

Perspective distance (px) ............ 500 → 1600
  └─ 3D perspective (default: 900px)
  └─ Tips: 500=close, 900=normal, 1600=far

Proximity distance (px) .............. 80 → 400
  └─ How far away effects activate (default: 200px)
  └─ Tips: 80=close, 200=medium, 400=far away

Proximity sensitivity (%) ............ 50 → 300
  └─ Effect strength (default: 150%)
  └─ Tips: 50=subtle, 150=normal, 300=dramatic

Card tilt ............................ ON/OFF
  └─ Cards tilt toward cursor (default: ON)

Card lift (px) ....................... 0 → 14
  └─ How high cards lift (default: 5px)
  └─ Tips: 0=no lift, 5=medium, 14=high

Mouse light .......................... ON/OFF
  └─ Spotlight follows cursor (default: ON)

Light size (px) ...................... 160 → 800
  └─ Spotlight area size (default: 420px)
  └─ Tips: 160=small, 420=medium, 800=large

Light strength (%) ................... 0 → 100
  └─ Spotlight brightness (default: 55%)
  └─ Tips: 0=invisible, 55=medium, 100=bright

Neon edge glow ....................... ON/OFF
  └─ Hover glow effect (default: ON)

Glow intensity (%) ................... 10 → 80
  └─ Glow brightness (default: 35%)
  └─ Tips: 10=subtle, 35=medium, 80=dramatic
```

### MOTION TAB
```
Motion speed (%) ..................... 0 → 100
  └─ Animation timing (default: 55%)
  └─ Tips: 0=instant, 55=medium, 100=slow

Smooth transitions ................... ON/OFF
  └─ Button/card animations (default: ON)

Load animations ...................... ON/OFF
  └─ Content reveal on page load (default: ON)

Matrix background .................... ON/OFF
  └─ Animated falling code (default: OFF)

Matrix density (%) ................... 10 → 100
  └─ Character density (default: 55%)
  └─ Tips: 10=sparse, 55=medium, 100=dense

Matrix speed (%) ..................... 10 → 100
  └─ Fall speed (default: 48%)
  └─ Tips: 10=slow, 48=medium, 100=fast
```

## 🚀 Quick Tuning Tips

### If Effects Are Too Strong
1. ↓ Proximity Sensitivity (start at 100%)
2. ↓ Glow Intensity (start at 25%)
3. ↓ Depth Strength (start at 8%)

### If Effects Are Too Subtle
1. ↑ Proximity Sensitivity (try 200%)
2. ↑ Proximity Distance (try 300px)
3. ↑ Glow Intensity (try 50%)

### If Text Is Hard to Read
1. ↑ Text Contrast (slide right)
2. ↓ Glass Opacity (slide left)
3. ↓ Background Dim (slide left)

### If Performance Is Laggy
1. ↓ Glass Blur (start at 14px)
2. OFF Matrix Background
3. ↓ Motion Speed (start at 30%)
4. OFF 3D Depth Effects

### If Effects Don't Show Near Cursor
1. ↑ Proximity Distance (try 300px)
2. ↑ Proximity Sensitivity (try 150%)
3. Ensure "3D depth effect" is ON

## 🔄 Preset Switching Workflow

```
1. Click extension icon (popup opens)
2. Click Quick themes button (Aurora, Neon, etc.)
3. Instant application of preset
4. Adjust sliders if needed
5. Click Save button
6. "Saved ✓" confirmation appears
```

---

## 💾 Settings Actions

### Save Settings
```
1. Make changes
2. Click blue "Save" button
3. Wait for "Saved ✓"
4. Settings persist across restarts
```

### Reset to Defaults
```
1. Click "Reset" button
2. All settings return to Aurora defaults
3. Click Save to confirm
```

### Load Preset
```
1. Click any Quick themes button
2. Instantly applies preset
3. Can still adjust individual settings
4. Shows as "Custom" if modified
```
