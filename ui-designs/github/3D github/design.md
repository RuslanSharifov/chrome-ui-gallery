## Use
Open `chrome://extensions`, enable Developer mode, choose **Load unpacked** and select this directory (containing `manifest.json`). Reload the GitHub tab after applying changes.

**Suitable for:** 3D hover and proximity interaction studies, browser UI themes, and experimental developer dashboards.
